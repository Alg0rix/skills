# skills

Skills live under `skills/<category>/<name>/SKILL.md`.

- `development/` — how you write and read code
- `testing/` — what gets a test
- `productivity/` — workflow playbooks
- `drafts/` — not ready
- `deprecated/` — retired, do not install

Optional `agents/openai.yaml` is Codex metadata (display name, implicit invocation).
